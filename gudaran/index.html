ぐだらん

1台のiPhoneをみんなで回して遊ぶ、飲み会・宴会向けのパーティーゲーム集です。究極の二択、せーので指差し、チンチロ、少数派ゲーム、山手線ゲーム、キングスカップ、ドキドキ風船、10秒ストップ、ぐだらん競馬の9種類を収録しています。

よくある質問

1日に遊べる回数は？
無料では、どのゲームも1日1回ずつ遊べます。動画を最後まで見ると、そのゲームをあと3回遊べます。日付が変わると回数は元に戻ります。

ぐだらんプレミアムとは？
月額780円の自動更新サブスクリプションで、広告が出なくなり、全ゲームを回数無制限で遊べます。解約は iPhone の「設定」＞ Apple ID ＞「サブスクリプション」から、いつでも行えます。

機種変更したら？
アプリのプレミアム画面の「購入を復元」を押すと、同じ Apple ID で加入中のプレミアムが使えるようになります。
